ความรุนแรงปานกลาง 26 พ.ย. 2569 ฟิชชิงAiTMGoogleMicrosoft 365

ชุดฟิชชิง DOMDIFFER หลบระบบป้องกันได้มากที่สุด ใช้หน้าล็อกอินจริงของ Google

สรุปสั้นๆ

Push Security จัดอันดับชุดเครื่องมือฟิชชิงที่หลุดผ่านระบบป้องกันขององค์กรได้บ่อยที่สุด อันดับหนึ่งคือ DOMDIFFER ที่ส่ง ‘หน้าล็อกอินจริง’ ของ Google และ Microsoft จากเบราว์เซอร์ของแฮกเกอร์มาให้เหยื่อเห็น จึงแยกจากของจริงได้ยากมาก

📰 เกิดอะไรขึ้น

Push Security บริษัทด้านความปลอดภัยเบราว์เซอร์ วัดค่าที่เรียกว่า breakthrough rate คือสัดส่วนการโจมตีฟิชชิงที่หลุดผ่านทั้งตัวกรองอีเมล เว็บเกตเวย์ และระบบ Safe Browsing จนไปถึงตัวผู้ใช้ได้จริง

ตั้งแต่ ส.ค. ถึง ต.ค. 2026 ชุดฟิชชิงชื่อ DOMDIFFER ครองอันดับหนึ่งทุกเดือน หลุดผ่านระบบป้องกันได้บ่อยกว่าอันดับสอง 2-4 เท่า เป้าหมายคือบัญชี Google และ Microsoft ขององค์กร และเหยื่อส่วนใหญ่มาจากคำเชิญนัดหมายปฏิทินปลอม

ตัวอย่างการโจมตีจริงเริ่มจากแจ้งเตือนปลอมของ Google Voice ว่ามีข้อความเสียงใหม่ ลิงก์จะผ่านด่านตรวจบอตเพื่อหลบเครื่องสแกน แล้วแสดงหน้าล็อกอิน Google ที่ไม่ใช่ภาพหรือหน้าก๊อปปี้ แต่เป็นหน้าจริงที่ถูก ‘สะท้อน’ มาจากเบราว์เซอร์ของแฮกเกอร์

รายงานยังเตือนว่าครึ่งหนึ่งของการโจมตีไม่ได้มาทางอีเมลเลย แต่มาจากโฆษณาบนเสิร์ชเอนจิน แชต โซเชียลมีเดีย คำเชิญปฏิทิน หรือ QR code และโดเมนจะเปลี่ยนทุกไม่กี่วัน ทำให้ระบบบล็อกตามตามไม่ทัน

🔎 ข้อมูลเพิ่มเติมจากแหล่งอื่น

Push Security อธิบายว่าชุดฟิชชิงแบบ AiTM ส่งต่อการล็อกอินได้ 4 แบบ คือ reverse proxy, หน้าเลียนแบบ, pixel streaming และ DOM mirroring ซึ่งแบบหลังสุดโตเร็วที่สุดในปี 2026 เพราะเบราว์เซอร์จริงของแฮกเกอร์เป็นคนล็อกอิน ระบบของ Google จึงเห็นสัญญาณเหมือนผู้ใช้ปกติ

ชุดฟิชชิงยุคใหม่ยังเลือก ‘อาวุธ’ ตามเครื่องของเหยื่อ เช่น ผู้ใช้ Windows อาจโดนหลอกให้ติดตั้งโปรแกรมควบคุมระยะไกล หรือโดน device code phishing ที่ให้เหยื่อล็อกอินบนหน้าจริงของ Microsoft แล้วกดอนุญาตให้แฮกเกอร์เข้าบัญชี ซึ่ง passkey ป้องกันไม่ได้

👥 ใครได้รับผลกระทบ

  • พนักงานองค์กรที่ใช้บัญชี Google Workspace หรือ Microsoft 365
  • ทีมไอทีที่พึ่งพาเฉพาะตัวกรองอีเมลและเว็บเกตเวย์
  • ผู้ใช้ที่ได้รับคำเชิญปฏิทิน แจ้งเตือนข้อความเสียง หรือ QR code ที่ไม่ได้คาดไว้

✅ ควรทำอย่างไร

  • เปิดใช้ passkey หรือกุญแจความปลอดภัย (FIDO2) สำหรับบัญชีงาน เพราะหยุด AiTM ได้
  • ปิดหรือจำกัดการล็อกอินแบบ device code ใน Microsoft Entra ID ถ้าองค์กรไม่ได้ใช้
  • อบรมพนักงานว่าลิงก์ฟิชชิงมาได้จากปฏิทิน แชต โฆษณา และ QR code ไม่ใช่แค่อีเมล
  • ถ้าเผลอกรอกรหัสในหน้าน่าสงสัย ให้เปลี่ยนรหัสทันทีและแจ้งทีมไอทีให้ยกเลิก session ที่ค้างอยู่
  • อย่าติดตั้งโปรแกรมหรือคัดลอกคำสั่งตามที่หน้าเว็บบอก แม้จะดูเหมือนหน้าของบริษัทใหญ่

📖 คำศัพท์น่ารู้

Phishing Kit
ชุดเครื่องมือสำเร็จรูปสำหรับทำเว็บหลอกขโมยรหัสผ่าน ที่มิจฉาชีพซื้อหรือเช่ามาใช้ได้ทันที
AiTM (Adversary-in-the-Middle)
การที่แฮกเกอร์แทรกตัวกลางระหว่างเหยื่อกับเว็บจริง ทำให้ขโมยได้ทั้งรหัสผ่านและ session แม้เปิด 2FA แบบ OTP
DOM Mirroring
เทคนิคส่งโครงสร้างหน้าเว็บจริงจากเบราว์เซอร์แฮกเกอร์มาสร้างใหม่บนเครื่องเหยื่อ หน้าตาจึงเหมือนของจริงทุกอย่าง
Passkey
วิธีล็อกอินแบบไม่ใช้รหัสผ่าน ผูกกับอุปกรณ์และโดเมนจริง จึงใช้กับเว็บปลอมไม่ได้
