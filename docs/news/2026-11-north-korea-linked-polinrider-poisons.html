ความรุนแรงสูง 26 พ.ย. 2569 Supply ChainเกาหลีเหนือGitHubมัลแวร์

แฮกเกอร์เกาหลีเหนือฝังมัลแวร์ใน GitHub กว่า 7,600 โปรเจกต์

สรุปสั้นๆ

แคมเปญ PolinRider ที่เชื่อมโยงกับเกาหลีเหนือแอบฝังโค้ดอันตรายลงในโปรเจกต์บน GitHub กว่า 7,600 แห่ง แค่นักพัฒนาสั่ง build โปรเจกต์ หรือบางครั้งแค่เปิดโฟลเดอร์ใน VS Code มัลแวร์ก็ทำงานทันที เป้าหมายคือขโมยรหัสผ่าน คุกกี้ และกระเป๋าเงินคริปโต

📰 เกิดอะไรขึ้น

นักวิจัยหลายทีมพบว่ากลุ่มแฮกเกอร์ที่เชื่อมโยงกับเกาหลีเหนือใช้แคมเปญชื่อ PolinRider แอบใส่โค้ดอันตรายที่เรียกว่า loader ลงในโปรเจกต์โอเพนซอร์สบน GitHub โดย Apiiro ประเมินว่ามีอย่างน้อย 7,609 repository จาก 2,330 บัญชีที่โดนแล้ว ส่วนใหญ่เป็นของนักพัฒนาทั่วไป และมีการฝังเพิ่มถึง 2,040 repository ในช่วง 27 ต.ค. ถึง 6 พ.ย. 2026 เพียงช่วงเดียว

วิธีที่แฮกเกอร์ใช้คือขโมย GitHub token จากเครื่องของนักพัฒนาที่ติดมัลแวร์อยู่แล้ว จากนั้นแก้ไข commit เดิมของเจ้าของโปรเจกต์ โดยคงชื่อผู้เขียน ข้อความ และวันที่ไว้เหมือนเดิม แล้วซ่อน loader ไว้หลังช่องว่างหลายร้อยตัวในไฟล์ตั้งค่า ทำให้ตรวจดูด้วยตาได้ยากมาก

จุดที่แยบยลคือ loader ไม่ได้เก็บที่อยู่เซิร์ฟเวอร์ควบคุม (C2) ไว้ในโค้ด แต่ไปอ่านจากธุรกรรมบนบล็อกเชน Ethereum แทน เทคนิคนี้ถูกเรียกว่า NullReceiver ต่อให้เซิร์ฟเวอร์ถูกปิด แฮกเกอร์ก็แค่ส่งธุรกรรมใหม่ครั้งเดียว loader ทุกตัวก็ย้ายไปเซิร์ฟเวอร์ใหม่ทันที

แคมเปญนี้ถูกมองว่าทำงานคู่ขนานกับ Contagious Interview ซึ่งหลอกนักพัฒนาด้วยการรับสมัครงานปลอม ให้ทำแบบทดสอบเขียนโค้ดหรือติดตั้ง "ไดรเวอร์กล้อง" ที่จริงคือมัลแวร์

🔎 ข้อมูลเพิ่มเติมจากแหล่งอื่น

SafeDep รายงานว่ารอบล่าสุดแฮกเกอร์เปลี่ยนมาใช้ loader ภาษา Python ยาวประมาณ 58 บรรทัด ซ่อนอยู่ในแพ็กเกจ utils เล็กๆ หรือในไฟล์ conftest.py เมื่อ Python import ไฟล์นี้ มันจะอ่านธุรกรรมล่าสุดจากกระเป๋า Ethereum แล้วถอดออกมาเป็นโค้ด JavaScript ไปรันด้วย Node.js โดยพบใน 375 repository จาก 260 บัญชี และยังไม่พบหลักฐานว่าถูกเผยแพร่ผ่าน PyPI หรือ npm

StepSecurity พบว่าบัญชี GitHub ชื่อ Eternity0207 เปิด pull request กว่า 200 รายการไปยังโปรเจกต์อย่าง AsyncAPI Generator, CircuitVerse และ Open Food Facts แล้ว force-push โค้ดอันตรายเข้าไปค้างไว้ราว 30-40 นาทีก่อนลบออก ทำให้ผลต่าง (diff) สุดท้ายดูสะอาด บัญชีนี้ถูกระงับแล้ว

OpenSourceMalware พบหลักฐานว่าแคมเปญนี้อาจเริ่มตั้งแต่ ก.พ. 2025 โดยมีการยึดบัญชีผู้ดูแลแพ็กเกจ npm ตระกูล itsa-* แล้วปล่อยเวอร์ชันอันตราย 9 แพ็กเกจภายใน 90 นาที ซึ่งปล่อย backdoor ชื่อ InvisibleFerret

👥 ใครได้รับผลกระทบ

  • นักพัฒนาซอฟต์แวร์ที่ clone หรือ build โปรเจกต์โอเพนซอร์สจาก GitHub
  • เจ้าของ repository ที่เครื่องหรือ GitHub token ถูกขโมย
  • องค์กรที่นำโค้ดโอเพนซอร์สมาใช้ในระบบโดยไม่ตรวจสอบ
  • ผู้หางานสายไอทีที่ได้รับข้อเสนองานหรือแบบทดสอบเขียนโค้ดจากเว็บที่ไม่น่าเชื่อถือ

✅ ควรทำอย่างไร

  • ตรวจไฟล์ conftest.py, โฟลเดอร์ utils, ไฟล์ตั้งค่า build และ .vscode/tasks.json ในโปรเจกต์ว่ามีโค้ดแปลกๆ หรือช่องว่างยาวผิดปกติหรือไม่
  • อย่าเปิดโปรเจกต์ที่ไม่รู้ที่มาใน VS Code โดยกด Trust ทันที ให้เปิดในโหมด Restricted Mode ก่อน
  • เปิดใช้ branch protection และห้าม force-push บน branch หลัก พร้อมตรวจประวัติ commit ที่ถูกแก้ย้อนหลัง
  • เปลี่ยน GitHub token และรหัสผ่านทันทีหากสงสัยว่าเครื่องติดมัลแวร์ และเปิดใช้ 2FA
  • ระวังการสมัครงานที่ให้รันโค้ด ติดตั้ง ‘ไดรเวอร์’ หรือคัดลอกคำสั่งไปวางใน Terminal

📖 คำศัพท์น่ารู้

Supply Chain Attack
การโจมตีผ่านซอฟต์แวร์หรือโค้ดที่คนอื่นนำไปใช้ต่อ เหมือนวางยาที่ต้นน้ำแล้วคนปลายน้ำโดนหมด
Loader
โค้ดชิ้นเล็กที่มีหน้าที่ไปดาวน์โหลดมัลแวร์ตัวจริงมาติดตั้งต่อ
C2 (Command and Control)
เซิร์ฟเวอร์ที่แฮกเกอร์ใช้สั่งงานเครื่องที่ติดมัลแวร์
Force-push
การเขียนทับประวัติโค้ดใน Git ทำให้ซ่อนร่องรอยการแก้ไขได้
